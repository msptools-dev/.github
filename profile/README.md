# Welcome to msptools-dev 👋

**msptools-dev** is a community-driven organization building open-source tools, automation, and integrations for Microsoft Partner (MSP) professionals and managed service providers.

---

## 🚀 What We Build

- **Automation & Scripting** – PowerShell modules, runbooks, and scripts to streamline MSP workflows
- **Integrations** – Connectors and adapters for popular PSA, RMM, and documentation platforms
- **Tooling & Utilities** – CLI tools and helpers to make day-to-day MSP operations faster and more reliable
- **Templates & Policies** – Reusable GitHub Actions workflows, branch protection rules, and org-wide defaults
